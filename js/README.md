# Agenda de Eventos Locales

## Descripción
Aplicación en javascript que almacena y muestra la colección de eventos locales mediante un array de objetos.

## Campos del evento

Cada evento contiene:

- id: identificador único
- nombre: nombre del evento
- fecha: fecha de celebración
- lugar: ubicación del evento
- categoria: tipo de evento
- precio: coste de entrada en euros
- plazas: número máximo de asistentes
